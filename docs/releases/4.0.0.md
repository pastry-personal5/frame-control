# Version v4.0.0

Version v4.0.0 delivers Phase 4, a broad product improvement release for Framecontrol.

Highlights:

- Multiple backend support for Draw Things and H3 behind one queue and execution model.
- H3 `i2av` and `r2av` pipelines with ordered references, native audio preservation, reproducible rendering controls, color metadata, and opt-in bounded color correction.
- Version-2 job files with named settings profiles, scoped defaults, mixed backend chains, and frozen per-run plans.
- TUI improvements including clearer interaction terminology, contextual shortcut help, richer execution details, safer queue actions, notifications, log scrolling, and configurable file opening.
- Measured per-stage timing and server-computed completion forecasts shared consistently by the TUI, CLI, HTTP API, gRPC, and MCP interfaces.
- External timing knobs with provisional calibration, held-out validation, guarded tuning, backups, rollback, and owner pins.

The release includes the completed Phase 4 cleanup and refactoring work. Apple Silicon host acceptance and extended owner-host timing checks remain documented as post-release validation.
